# 拆书 × 优势

用拆书助力优势正向发挥的优势教练 · 个人品牌单页站。

线上地址：https://cherry-wlz.github.io/

## 站点结构

一页式长滚动，八个区块按固定顺序排列（痛点共鸣必须排在「关于我」之前）：

1. 首屏 — 主标题、副标题、两个按钮
2. 痛点共鸣 — 三类访客的三句话
3. 关于我 — 品牌故事、资质、优势拆书三阶法、差异化对照
4. 服务矩阵 — 三张服务卡 + 合作流程四步
5. 客户案例 — 三段式案例（待真实内容替换）
6. 拆书活动 — 近期活动与往期回顾（待补）
7. 信任区 — 常见问题 6 条 + 客户评价（待补）
8. 转化区 — 7 字段留资表单

## 技术

- Vite + React + Tailwind CSS 4，纯前端静态站
- 样式集中在 `src/index.css`，柔雾浅色主题（雾紫 `#F4F2FB` / 薰衣草 `#7A6BB5` / 深紫黑 `#2E2A42`）
- 页面内容集中在 `src/pages/Home.jsx`
- 推送 `main` 后由 `.github/workflows/deploy.yml` 自动构建并发布到 GitHub Pages
